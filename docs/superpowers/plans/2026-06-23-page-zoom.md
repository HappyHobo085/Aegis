## Goal

Give the user per-tab page zoom — keyboard (Ctrl + / Ctrl − / Ctrl 0) **and** a small toolbar
affordance (zoom indicator/menu) — applied through each of the four content engines (WebKitGTK,
WebView2, WKWebView, Android WebView), surfaced consistently in the chrome, and reaching all
platforms to the same level (subject to §4 verification reality). v1 persistence is **session-only**
(decision + justification below).

## Architecture

```
  ┌─ chrome (React) ─────────────────────────────┐        ┌─ Rust core (src-tauri) ─────────────┐
  │ useZoom(activeTabId)                          │  ipc   │ zoom.rs::dispatch()                 │
  │   ├─ Ctrl +/−/0 keydown (App.tsx)             │ ─────▶ │   zoom.get  → ZoomStore[id]         │
  │   ├─ Ctrl-wheel (App.tsx, non-passive)        │        │   zoom.set  → clamp+store, then     │
  │   └─ ZoomIndicator (toolbar)                  │        │     apply to the tab's webview via  │
  │        ⤷ aegis.zoom.set / .reset / .get       │        │     per-platform setter             │
  │   ← zoom.changed event (label-keyed)          │ ◀───── │   emits zoom.changed {viewId,factor}│
  └───────────────────────────────────────────────┘        │   apply_to_tab(id) on spawn (replay)│
                                                            └──────────────────────────────────────┘
        per-platform setters (one per engine, gated):
          Linux   linux_layout::set_zoom_level_label  → WebViewExt::set_zoom_level(f64)
          Windows zoom_win::set                       → ICoreWebView2::SetZoomFactor(f64)
          macOS   zoom_mac::set                       → WKWebView::setPageZoom(CGFloat)
          Android MainActivity Bridge.setZoom(int pct)→ WebSettings.textZoom (per-tab WebView)
```

The Rust core owns the **canonical per-tab zoom factor** (a `HashMap<u32, f64>` in managed state)
so the value survives a tab discard→reload (the webview is destroyed and respawned; the core
replays the stored factor at spawn) and so every engine is driven from one place. The chrome is a
thin client: it sends `zoom.set(viewId, factor)` and renders `zoom.changed`.

**Why the core owns it, not the renderer:** a discarded background tab loses its webview entirely
(`tabs.rs` idle sweep); on reactivation `nav::spawn_tab` rebuilds it at zoom 1.0 unless the core
re-applies. The renderer's `useZoom` is purely presentational + an input source.

## v1 persistence decision: **SESSION-ONLY** (not per-origin)

**Decision:** v1 stores the zoom factor **per live tab, in memory only** (a managed Rust
`HashMap<viewId, f64>`). It is **not** written to disk and **not** keyed by origin. A new tab starts
at 1.0; a discarded→reloaded tab keeps its factor (the core replays it at respawn); closing the app
forgets all zoom.

**Justification (the spec explicitly allows session-only for v1, line 100):**

- **Per-origin would need a real store + a sync contract.** Every persisted store in this repo
  (`settings.rs`, `places.rs`, `subs.rs`, …) routes through `jsonstore::write_atomic` and most also
  carry an HLC sync projection (see `settings.rs` per-key projection). A per-origin zoom map is a
  new syncable store — that's a meaningfully larger surface (new file, atomic writes, a merge rule,
  an export/import leg in `data.rs`, sync wiring) than the spec's scope for E, and it overlaps
  sub-projects that own data hardening (C) and sync. Keeping v1 in memory avoids a half-built store.
- **The hard part of per-origin is re-application on navigation, not storage.** WebKitGTK/WebView2
  zoom is **per-webview**, not per-document — it persists across in-tab navigations already (the
  engine keeps the factor until we change it). To make zoom track the _origin_ you'd have to detect
  every main-frame origin change (the SPA `pushState`/hash case that `nav_url_*` already wrestles
  with) and look up + re-apply — a per-platform navigation-coupled feature, not a storage feature.
  That's a clean v2 increment on top of this v1, not a prerequisite.
- **Session-per-tab already delivers the headline UX:** Ctrl +/−/0 and Ctrl-wheel adjust the page,
  the change sticks while you browse that tab (incl. across reloads/discards), and the toolbar shows
  the level. The contract (`zoom.set(viewId, factor)` + a label-keyed store) is forward-compatible:
  v2 per-origin can layer a disk store + a `notify::uri`/`SourceChanged` re-apply hook **without
  changing the IPC surface**.

This is recorded in `zoom.rs`'s module doc and the `shared/types.ts` comment so the v2 path is
explicit.

## Constants (single source — define once in BOTH `src/lib/zoom.ts` and `zoom.rs`, kept identical)

- `ZOOM_MIN = 0.5`, `ZOOM_MAX = 3.0`, `ZOOM_DEFAULT = 1.0`.
- Discrete steps: `[0.5, 0.67, 0.8, 0.9, 1.0, 1.1, 1.25, 1.5, 1.75, 2.0, 2.5, 3.0]` (Chrome's
  ladder, trimmed). `stepZoom(factor, +1|-1)` snaps to the nearest ladder rung then moves one.
- `clampZoom(f)` = clamp to `[ZOOM_MIN, ZOOM_MAX]`.
- Android translation: `textZoom = round(factor * 100)` (a percentage int; default 100).

### Task 1 — Pure zoom math (`src/lib/zoom.ts`) + tests

**Files:** `src/lib/zoom.ts` (NEW), `src/lib/zoom.test.ts` (NEW).

**Step (one action):** add the pure module.

```ts
// src/lib/zoom.ts
export const ZOOM_MIN = 0.5;
export const ZOOM_MAX = 3.0;
export const ZOOM_DEFAULT = 1.0;

/** Chrome-style discrete zoom ladder. */
export const ZOOM_STEPS = [0.5, 0.67, 0.8, 0.9, 1.0, 1.1, 1.25, 1.5, 1.75, 2.0, 2.5, 3.0];

export function clampZoom(f: number): number {
  if (!Number.isFinite(f)) return ZOOM_DEFAULT;
  return Math.min(ZOOM_MAX, Math.max(ZOOM_MIN, f));
}

/** Snap `f` to the nearest ladder rung, then move `dir` (+1 in / −1 out) one rung; clamped. */
export function stepZoom(f: number, dir: 1 | -1): number {
  const cur = clampZoom(f);
  // nearest rung index
  let i = 0;
  let best = Infinity;
  ZOOM_STEPS.forEach((s, idx) => {
    const d = Math.abs(s - cur);
    if (d < best) {
      best = d;
      i = idx;
    }
  });
  const ni = Math.min(ZOOM_STEPS.length - 1, Math.max(0, i + dir));
  return ZOOM_STEPS[ni];
}

/** "100%", "125%" … for the indicator. */
export function formatZoom(f: number): string {
  return `${Math.round(clampZoom(f) * 100)}%`;
}
```

**Tests (`src/lib/zoom.test.ts`):**

```ts
import { describe, it, expect } from 'vitest';
import { clampZoom, stepZoom, formatZoom, ZOOM_MIN, ZOOM_MAX } from './zoom';

describe('zoom math', () => {
  it('clamps to range and guards non-finite', () => {
    expect(clampZoom(0.1)).toBe(ZOOM_MIN);
    expect(clampZoom(9)).toBe(ZOOM_MAX);
    expect(clampZoom(1.25)).toBe(1.25);
    expect(clampZoom(NaN)).toBe(1.0);
  });
  it('steps along the ladder and stops at the ends', () => {
    expect(stepZoom(1.0, 1)).toBe(1.1);

    expect(stepZoom(0.5, -1)).toBe(0.5); // clamped at min
    expect(stepZoom(3.0, 1)).toBe(3.0); // clamped at max
    expect(stepZoom(1.18, 1)).toBe(1.5); // snaps to 1.25 then +1
  });
  it('formats percent', () => {
    expect(formatZoom(1.0)).toBe('100%');
    expect(formatZoom(1.25)).toBe('125%');
```

```ts
// in AndroidBridge interface:
  /** Set page zoom for tab `id` (percentage int, 100 == 1.0). No-op off Android. */
  setZoom(id: number, percent: number): void;

// in aegis object:
  zoom: {
    get: (viewId) => {
      const a = androidBridge();
      if (a) return Promise.resolve({ viewId, factor: androidZoom.get(viewId) ?? 1.0 });
      return call<ZoomState>(IPC.zoomGet, { viewId });
    },
    set: (viewId, factor) => {
      const a = androidBridge();
      if (a) {
        const f = clampZoom(factor);
        androidZoom.set(viewId, f);
        a.setZoom(viewId, Math.round(f * 100));
        // No native event bus on Android content side; push to onChanged subscribers, mirroring nav.onState.
        (window as unknown as { __aegisZoomChanged?: (s: ZoomState) => void }).__aegisZoomChanged?.({ viewId, factor: f });
        return Promise.resolve({ viewId, factor: f });
      }
      return call<ZoomState>(IPC.zoomSet, { viewId, factor });
    },
    reset: (viewId) => aegis.zoom.set(viewId, 1.0),
    onChanged: (cb) => {
      if (androidBridge()) {
        const w = window as unknown as {
          __aegisZoomChangedCbs?: Set<(s: ZoomState) => void>;
          __aegisZoomChanged?: (s: ZoomState) => void;
        };
        const cbs = (w.__aegisZoomChangedCbs ??= new Set());
        cbs.add(cb);
        w.__aegisZoomChanged = (s) => cbs.forEach((f) => f(s));
        return () => { cbs.delete(cb); };
      }
      return on<ZoomState>(IPC.evtZoomChanged, cb);
    },
  },
```

### Task 4 — `useZoom` hook + test

**Files:** `src/hooks/useZoom.ts` (NEW), `src/hooks/useZoom.test.tsx` (NEW).

**Step:** the hook keyed on the active tab id — fetches the factor on mount/tab-switch, subscribes
to `onChanged` (filtered to the active id), and exposes `zoomIn` / `zoomOut` / `reset` / `setFactor`.

```ts
// src/hooks/useZoom.ts
import { useCallback, useEffect, useState } from 'react';
import type { ViewId } from '../../shared/types';
import { aegis } from '../lib/ipcClient';
import { stepZoom, clampZoom, ZOOM_DEFAULT } from '../lib/zoom';

export function useZoom(activeId: ViewId) {
  const [factor, setFactor] = useState(ZOOM_DEFAULT);

  useEffect(() => {
    let live = true;
    void aegis.zoom.get(activeId).then((s) => {
      if (live) setFactor(s.factor);
    });
    return () => {
      live = false;
    };
  }, [activeId]);

  useEffect(() => {
    return aegis.zoom.onChanged((s) => {
      if (s.viewId === activeId) setFactor(s.factor);
    });
  }, [activeId]);

  const apply = useCallback(
    (f: number) => {
      const c = clampZoom(f);
      setFactor(c); // optimistic; onChanged confirms
      void aegis.zoom.set(activeId, c);
    },
    [activeId],
  );

  const zoomIn = useCallback(() => apply(stepZoom(factor, 1)), [apply, factor]);
  const zoomOut = useCallback(() => apply(stepZoom(factor, -1)), [apply, factor]);
  const reset = useCallback(() => {
    setFactor(ZOOM_DEFAULT);
    void aegis.zoom.reset(activeId);
  }, [activeId]);

  return { factor, zoomIn, zoomOut, reset, setFactor: apply };
}
```

   ```tsx
       if (!e.ctrlKey || e.altKey || e.metaKey) return;
       if (e.key === '+' || e.key === '=' || e.code === 'NumpadAdd') {
         e.preventDefault();
         zoom.zoomIn();

         e.preventDefault();
         zoom.zoomOut();
       } else if (e.key === '0' || e.code === 'Numpad0') {
         e.preventDefault();
         zoom.reset();
       }
     };
     window.addEventListener('keydown', onKey);
     return () => window.removeEventListener('keydown', onKey);
   }, [zoom.zoomIn, zoom.zoomOut, zoom.reset]);
   ```

### Task 7 — Rust core: `zoom.rs` (store + dispatch + pure clamp + replay) + unit tests

**Files:** `src-tauri/src/zoom.rs` (NEW), `src-tauri/src/lib.rs` (EDIT: `mod zoom;`,
`.manage(zoom::ZoomStore::default())`, and a `zoom::dispatch` arm in `ipc()` before the fallthrough).

**Step:** the Tauri-layer module. `clamp` is pure + unit-tested; `dispatch` reads `viewId`/`factor`,
clamps, stores, applies via the per-platform fan-out, emits `zoom.changed`, returns the `ZoomState`.

```rust
//! Page zoom (zoom.* IPC). v1 is SESSION-ONLY: the factor is held in an in-memory
//! per-tab map (NOT persisted, NOT per-origin — see the design doc §"persistence
//! decision"). The core owns the canonical value so a discarded→reloaded tab keeps
//! its zoom (replayed at spawn via `apply_to_tab`). v2 (per-origin) can layer a disk
//! store + a main-frame-origin re-apply hook WITHOUT changing this IPC surface.
use std::collections::HashMap;
use std::sync::Mutex;

use serde_json::{json, Value};
use tauri::{AppHandle, Manager};

pub const ZOOM_MIN: f64 = 0.5;
pub const ZOOM_MAX: f64 = 3.0;

#[derive(Default)]
pub struct ZoomStore(pub Mutex<HashMap<u32, f64>>);

/// Clamp to [ZOOM_MIN, ZOOM_MAX]; non-finite → 1.0. Pure (testable without Tauri).
pub fn clamp(f: f64) -> f64 {
    if !f.is_finite() {
        return 1.0;
    }
    f.max(ZOOM_MIN).min(ZOOM_MAX)
}

/// The stored factor for tab `id`, or 1.0 if unset.
pub fn factor_of(app: &AppHandle, id: u32) -> f64 {
    app.try_state::<ZoomStore>()
        .map(|s| *s.0.lock().unwrap().get(&id).unwrap_or(&1.0))
        .unwrap_or(1.0)
}

/// Store + apply a factor to a tab, then emit zoom.changed. Shared by set/reset.
fn put(app: &AppHandle, id: u32, factor: f64) -> Value {
    let f = clamp(factor);
    if let Some(s) = app.try_state::<ZoomStore>() {
        s.0.lock().unwrap().insert(id, f);
    }
    apply_native(app, id, f);
    let state = json!({ "viewId": id, "factor": f });
    crate::emit_event(app, "zoom.changed", state.clone());
    state
}

/// Re-apply a tab's stored factor to its (re)spawned webview. Called at the end of
/// `nav::spawn_tab` so a discard→reload keeps the user's zoom. No-op at 1.0.
pub fn apply_to_tab(app: &AppHandle, id: u32) {
    let f = factor_of(app, id);
    if (f - 1.0).abs() > f64::EPSILON {
        apply_native(app, id, f);
    }
}

/// Per-platform fan-out to the live webview. Each engine's setter is gated; the
/// non-matching arms are no-ops so the lib compiles for every target.
fn apply_native(app: &AppHandle, id: u32, factor: f64) {
    let _ = (app, id, factor); // silence unused on platforms with no setter (none today)
    let label = crate::nav::content_label(id);

    #[cfg(target_os = "linux")]
    crate::linux_layout::set_zoom_level_label(app, &label, factor);

    #[cfg(target_os = "windows")]
    if let Some(content) = app.get_webview(&label) {
        let _ = content.with_webview(move |pw| crate::zoom_win::set(&pw, factor));
    }

    #[cfg(target_os = "macos")]
    if let Some(content) = app.get_webview(&label) {
        let _ = content.with_webview(move |pw| crate::zoom_mac::set(&pw, factor));
    }
    // Android applies in MainActivity (native WebView the Rust core can't reach);
    // the chrome routes zoom.set through the AegisAndroid bridge instead of this dispatch.
}

/// Handle `zoom.*` channels. Returns `None` if not a zoom channel.
pub fn dispatch(app: &AppHandle, channel: &str, payload: &Value) -> Option<Result<Value, String>> {
    let active = || {
        app.try_state::<crate::tabs::Tabs>()
            .map(|s| s.reg.lock().unwrap().active_id())
            .unwrap_or(1)
    };
    let id = payload.get("viewId").and_then(Value::as_u64).map(|n| n as u32).unwrap_or_else(active);
    match channel {
        "zoom.get" => Some(Ok(json!({ "viewId": id, "factor": factor_of(app, id) }))),
        "zoom.set" => {
            let f = payload.get("factor").and_then(Value::as_f64).unwrap_or(1.0);
            Some(Ok(put(app, id, f)))
        }
        "zoom.reset" => Some(Ok(put(app, id, 1.0))),
        _ => None,
    }
}

#[cfg(test)]
mod tests {
    use super::*;
    #[test]
    fn clamp_bounds_and_nonfinite() {
        assert_eq!(clamp(0.1), ZOOM_MIN);
        assert_eq!(clamp(9.0), ZOOM_MAX);
        assert_eq!(clamp(1.25), 1.25);
        assert_eq!(clamp(f64::NAN), 1.0);
        assert_eq!(clamp(f64::INFINITY), 1.0);
    }
}
```

- `.manage(zoom::ZoomStore::default())` in the builder chain.
