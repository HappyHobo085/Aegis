## Goal

Add a user-configured, **content-webview-scoped network proxy** to Aegis, applied per platform on
the content webview(s) and toggleable on/off (off restores a direct connection). The user sets a
scheme (`http`/`socks5`), host, port, an optional bypass-host list, and a mode (`off`/`proxy`).
Labeled **"Proxy"** everywhere in the UI — **never "VPN"** — because a shell proxy routes only
browsed pages (not the OS, not the chrome's own updater/filter-list fetches) and is leaky
(WebRTC/DNS/QUIC), so it is honest geo/region-testing plumbing, **not anonymity**.

**Acceptance (from the design §3-M / §4):** traffic routes via the configured proxy on **Linux**
and **Android** (verified by observed egress on a proxy you run); the **off** state restores direct;
**Windows** compile-verified (`cargo check --target …`) + owner device-verifies; **macOS** is the
hand-rolled Network.framework binding — planned, **CI-build-only, explicitly at-risk** (may slip).

## Architecture

```
            ┌──────────────────────── chrome (React) ─────────────────────────┐
            │  ProxyTab.tsx  ── useProxy() ──►  aegis.proxy.{getState,setConfig,│
            │  (Settings ▸ Proxy)                          testConnection,clear}│
            └───────────────────────────────┬─────────────────────────────────┘
                                             │ invoke('ipc', {channel:'proxy.*'})
                                             ▼
                       src-tauri/src/proxy.rs   proxy::dispatch(app, channel, payload)
                       • ProxyConfig  (parse + validate, #[test]-covered, pure)
                       • managed ProxyState (Mutex<ProxyConfig>, like AdblockState)
                       • persisted in settings.json under a `proxy` key (NO secrets — see §Secrets)
                       • apply(app)  ──►  per-platform setter:
                             ├─ Linux   linux_layout::apply_proxy_label  (set_network_proxy_settings, LIVE)
                             ├─ Windows nav::spawn_tab additional_browser_args (--proxy-server, NEW TABS)
                             ├─ Android AegisAndroid.setProxy bridge ► ProxyController.setProxyOverride (PROCESS-GLOBAL)
                             └─ macOS   proxy_mac::apply  (hand-rolled Network.framework — GREENFIELD/CI-only)
                       • also called from nav::spawn_tab so new tabs inherit the proxy.
```

Config flows ONE way (chrome → core → per-platform setter). The core is the single source of truth
(persisted in `settings.json`'s `proxy` object); the platform setters are stateless appliers. "Off"
calls the same appliers with the "no proxy" mode so a toggle-off reliably restores direct.

## Global Constraints (from design §6 + the locked scope §2 + parity §4)

1. **Label "Proxy," never "VPN."** Every user-facing string (tab name, headings, descriptions, toasts)
   says "Proxy." No claim of a whole-device tunnel. Include the honest-limit disclosure copy in the tab
   (routes browsed pages only; doesn't cover the updater/filter-list fetches; WebRTC/DNS/QUIC can still
   leak — see the WebRTC setting). **This is a product-correctness requirement, not cosmetic.**
2. **Depends on the (done) WebRTC fix** so the privacy claim isn't hollow. Don't re-implement it; the
   ProxyTab copy points the user at the WebRTC setting.
3. **No secrets in `settings.json`.** `data.export` bundles `settings::all(app)` **verbatim**
   (`data.rs:34,37`) into the Downloads `aegis-export.json`. **v1 ships NO proxy auth** (username/password)
   — auth is "unconfirmed" on Android per the design, and storing it in settings would leak it into the
   export. If a later tier adds auth, it MUST live in the OS keychain (`sync_keystore.rs` `keyring::Entry`
   pattern) and be excluded from export — recorded as a deferred follow-up, not built here.
4. **IPC in three places** (design §6.1, `shared/CLAUDE.md`): a new channel goes in `shared/types.ts`
   (`IPC` const + payload type + `AegisApi` method), the Rust `ipc()` dispatcher (`lib.rs`), and
   `src/lib/ipcClient.ts`. Events stay dotted logically; `emit_event` rewrites `.`→`:`.
5. **Autopilot coverage in the same commit (drift-guarded).** New `proxy.*` command channels →
   `catalog.ts` entry (`channels` + `exercise` + a `verify(api)` round-trip, since proxy mutates user
   config). New "Proxy" settings tab → auto-generated `settings:proxy` screen (just add `'proxy'` to
   `SettingsModal` `TAB_ORDER`) + `reach.ts` label + interaction specs in `controls.ts`/`settings.ts`.
   `coverage.test.ts` fails the build if a `proxy.*` channel has no catalog entry.
6. **Gate per sub-project:** `npm test` green; for runtime-touching changes, the **live autopilot**
   `RESULT: … 0 failed` and `ad-block blocking (trace): PASS` on Linux (`bash scripts/autopilot/run-autopilot.sh`).
7. **Parity before "done" (design §4).** Bring Linux/Windows/macOS/Android to the same level subject to
   the hardware reality: Linux live, Android device, Windows `cargo check` + owner device, macOS CI-build
   (GUI verify = sub-project I, hardware-gated). **No "Linux works, the rest is a follow-up."**

## Data model / IPC contract (the exact shapes)

Add to `shared/types.ts`:

```ts
// IPC const — new command + event channels (proxy.* group)
proxyGetState: 'proxy.getState',
proxySetConfig: 'proxy.setConfig',
proxyTestConnection: 'proxy.testConnection',
proxyClear: 'proxy.clear',
// event (main -> chrome): the live proxy state after any change
evtProxyState: 'proxy.state',

/** A content-webview-scoped proxy. `mode:'off'` = direct (the default). Labeled
 *  "Proxy," not "VPN": routes browsed pages only, not the OS or the chrome's own
 *  fetches, and does NOT stop WebRTC/DNS/QUIC leaks (see `webrtcPolicy`). NO auth
 *  fields in v1 (credentials would leak into data.export and are unconfirmed on Android). */
export interface ProxyConfig {
  mode: 'off' | 'proxy';
  scheme: 'http' | 'socks5';
  host: string;            // hostname or IP; ignored when mode==='off'
  port: number;            // 1..65535; ignored when mode==='off'
  bypassHosts: string[];   // hosts that bypass the proxy (direct), e.g. ['localhost','*.internal']
}

/** Live proxy status for the Proxy settings UI. */
export interface ProxyState {
  config: ProxyConfig;
  active: boolean;         // mode==='proxy' AND a valid config was applied
  /** Per-platform application reality, surfaced honestly in the UI. */
  applied: 'live' | 'new-tabs-only' | 'process-global' | 'unsupported';
  lastError: string;       // '' when none
}

// AegisApi
proxy: {
  getState(): Promise<ProxyState>;
  setConfig(config: ProxyConfig): Promise<ProxyState>;
  /** Best-effort reachability probe against the configured proxy (TCP connect). */
  testConnection(config: ProxyConfig): Promise<{ ok: boolean; latencyMs?: number; error?: string }>;
  clear(): Promise<ProxyState>; // === setConfig({...mode:'off'}); convenience for the off button
  onState(cb: (s: ProxyState) => void): () => void;
};
```

> **Why dedicated `proxy.*` channels and not settings-only?** The proxy must be **applied
> imperatively** (Linux live `set_network_proxy_settings`; Android `setProxyOverride` via the bridge;
> a `testConnection` action). The `sync.*` namespace is the precedent for "config stored under
> settings + dedicated action channels." The `ProxyConfig` is still **persisted inside `settings.json`**
> under a `proxy` key (so `data.export`/`import` round-trips it and the settings store stays the one
> file), but the verbs are real channels. This makes the catalog entry mandatory (good — it forces a
> live `verify` round-trip).

Rust signatures (in `proxy.rs`):

```rust
#[derive(Clone, Debug, PartialEq, serde::Serialize, serde::Deserialize)]
pub struct ProxyConfig { pub mode: String, pub scheme: String, pub host: String, pub port: u16, pub bypass_hosts: Vec<String> }
impl Default for ProxyConfig { /* mode:"off", scheme:"http", host:"", port:8080, bypass: [] */ }

impl ProxyConfig {
    /// Parse from the persisted/IPC JSON, applying defaults + clamping. Pure + #[test]ed.
    pub fn from_value(v: &serde_json::Value) -> ProxyConfig;
    /// Whether this is a usable, ON proxy (mode=="proxy" && non-empty host && 1..=65535 port && known scheme). Pure.
    pub fn is_active(&self) -> bool;
    /// The default proxy URI WebKit/Chromium understands, e.g. "http://host:port" / "socks5://host:port".
    /// None when not active. Pure + #[test]ed.
    pub fn default_uri(&self) -> Option<String>;
}

pub struct ProxyState(pub std::sync::Mutex<ProxyConfig>);   // managed like AdblockState
pub fn dispatch(app: &AppHandle, channel: &str, payload: &Value) -> Option<Result<Value, String>>;
pub fn current(app: &AppHandle) -> ProxyConfig;             // read managed/persisted config
pub fn apply(app: &AppHandle);                              // re-apply to ALL existing content webviews + emit proxy.state
pub fn apply_to_tab(app: &AppHandle, id: u32);             // apply to one tab (called from nav::spawn_tab)
```

```rust
#[test]
fn from_value_applies_defaults_and_clamps() {
    let v = serde_json::json!({ "mode": "proxy", "scheme": "socks5", "host": "10.0.0.9", "port": 1080 });
    let c = ProxyConfig::from_value(&v);
    assert_eq!(c.mode, "proxy");
    assert_eq!(c.scheme, "socks5");
    assert_eq!(c.host, "10.0.0.9");
    assert_eq!(c.port, 1080);
    // Missing object → all defaults, OFF.
    let d = ProxyConfig::from_value(&serde_json::json!({}));
    assert_eq!(d.mode, "off");
    assert!(!d.is_active());
    // Out-of-range / zero port on an ON config → not active (won't be applied).
    let bad = ProxyConfig::from_value(&serde_json::json!({ "mode": "proxy", "host": "h", "port": 0 }));
    assert!(!bad.is_active());
}

#[test]
fn is_active_requires_on_mode_host_port_scheme() {
    let on = ProxyConfig { mode: "proxy".into(), scheme: "http".into(), host: "p.example".into(), port: 8080, bypass_hosts: vec![] };
    assert!(on.is_active());
    let off = ProxyConfig { mode: "off".into(), ..on.clone() };
    assert!(!off.is_active());
    let nohost = ProxyConfig { host: "".into(), ..on.clone() };
    assert!(!nohost.is_active());
    let badscheme = ProxyConfig { scheme: "ftp".into(), ..on.clone() };
    assert!(!badscheme.is_active());
}

#[test]
fn default_uri_builds_scheme_host_port_or_none_when_off() {
    let http = ProxyConfig { mode: "proxy".into(), scheme: "http".into(), host: "p".into(), port: 3128, bypass_hosts: vec![] };
    assert_eq!(http.default_uri().as_deref(), Some("http://p:3128"));
    let socks = ProxyConfig { scheme: "socks5".into(), ..http.clone() };
    assert_eq!(socks.default_uri().as_deref(), Some("socks5://p:3128"));
    assert_eq!(ProxyConfig { mode: "off".into(), ..http }.default_uri(), None);
}
```

       match channel {
           "proxy.getState" => Some(Ok(state_json(app))),
           "proxy.setConfig" | "proxy.clear" => {

                   ProxyConfig { mode: "off".into(), ..current(app) }

```rust
// linux_layout.rs
/// Apply the proxy config to one content webview's network session via WebKitGTK.
/// CUSTOM with a default URI when active; NO_PROXY (direct) when off/invalid. Live-switchable.
pub fn apply_proxy_label(app: &AppHandle, label: &str, cfg: &crate::proxy::ProxyConfig) {
    let Some(w) = app.get_webview(label) else { return };
    let uri = cfg.default_uri();                       // None when off/invalid
    let ignore: Vec<String> = cfg.bypass_hosts.clone();
    let _ = w.with_webview(move |pw| {
        use webkit2gtk::{WebViewExt, WebsiteDataManagerExt, NetworkProxyMode, NetworkProxySettings};
        let Some(mgr) = WebViewExt::website_data_manager(&pw.inner()) else { return };
        match uri {
            Some(u) => {
                let ignore_refs: Vec<&str> = ignore.iter().map(String::as_str).collect();
                let mut settings = NetworkProxySettings::new(Some(&u), &ignore_refs);
                // SOCKS proxies are typically scheme-agnostic, but set per-scheme too so http/https/ws all route.
                // (default_proxy_uri already covers all schemes; add_proxy_for_scheme is for finer control.)
                mgr.set_network_proxy_settings(NetworkProxyMode::Custom, Some(&mut settings));
            }
            None => mgr.set_network_proxy_settings(NetworkProxyMode::NoProxy, None),
        }
    });
}
```

```kotlin
import androidx.webkit.ProxyConfig
import androidx.webkit.ProxyController

@JavascriptInterface
fun setProxy(scheme: String, host: String, port: Int, bypass: String) = runOnUiThread {
    if (!WebViewFeature.isFeatureSupported(WebViewFeature.PROXY_OVERRIDE)) return@runOnUiThread
    val rule = "$scheme://$host:$port"                 // e.g. "socks5://10.0.0.9:1080" / "http://p:8080"
    val builder = ProxyConfig.Builder().addProxyRule(rule)
    // Bypass the chrome's own origin so the React UI isn't routed through the proxy, plus user bypasses.
    builder.bypassSimpleHostnames()
    builder.addDirect()                                 // fall through to direct if a rule doesn't match
    bypass.split(",").map { it.trim() }.filter { it.isNotEmpty() }.forEach { builder.addBypassRule(it) }
    try {
        ProxyController.getInstance().setProxyOverride(builder.build(), { it.run() }, { /* applied */ })
    } catch (t: Throwable) { Log.w("AegisProxy", "setProxyOverride failed", t) }
}

@JavascriptInterface
fun clearProxy() = runOnUiThread {
    if (!WebViewFeature.isFeatureSupported(WebViewFeature.PROXY_OVERRIDE)) return@runOnUiThread
    try { ProxyController.getInstance().clearProxyOverride({ it.run() }, { }) }
    catch (t: Throwable) { Log.w("AegisProxy", "clearProxyOverride failed", t) }
}

// proxy_mac.rs  (#[cfg(target_os = "macos")])
use objc2::{msg_send, runtime::AnyObject};
use objc2_foundation::{NSArray, NSString};

// Network.framework C entry points (link "Network" framework via build.rs cargo:rustc-link-lib=framework=Network).
#[allow(non_camel_case_types)] type nw_endpoint_t = *mut std::ffi::c_void;
#[allow(non_camel_case_types)] type nw_proxy_config_t = *mut std::ffi::c_void;
extern "C" {
    fn nw_endpoint_create_host(host: *const std::os::raw::c_char, port: *const std::os::raw::c_char) -> nw_endpoint_t;
    fn nw_proxy_config_create_http_connect(endpoint: nw_endpoint_t, tls: *mut std::ffi::c_void) -> nw_proxy_config_t;
    fn nw_proxy_config_create_socksv5(endpoint: nw_endpoint_t) -> nw_proxy_config_t;
}

pub fn apply_label(app: &tauri::AppHandle, label: &str, cfg: &crate::proxy::ProxyConfig) {
    let Some(w) = app.get_webview(label) else { return };
    let uri = cfg.default_uri();
    let (scheme, host, port) = (cfg.scheme.clone(), cfg.host.clone(), cfg.port);
    let _ = w.with_webview(move |pw| unsafe {
        // pw.inner() is the WKWebView (objc2). Reach websiteDataStore.proxyConfigurations.
        let wkwebview = pw.inner();                 // &WKWebView (objc2-web-kit)
        let config: *mut AnyObject = msg_send![wkwebview, configuration];
        let store: *mut AnyObject = msg_send![config, websiteDataStore];
        if uri.is_none() {
            let empty = NSArray::<AnyObject>::new();
            let _: () = msg_send![store, setProxyConfigurations: &*empty];   // direct
            return;
        }
        let host_c = std::ffi::CString::new(host).unwrap();
        let port_c = std::ffi::CString::new(port.to_string()).unwrap();
        let endpoint = nw_endpoint_create_host(host_c.as_ptr(), port_c.as_ptr());
        let proxy = if scheme == "socks5" { nw_proxy_config_create_socksv5(endpoint) }
                    else { nw_proxy_config_create_http_connect(endpoint, std::ptr::null_mut()) };
        // Wrap the nw_proxy_config_t in the array WKWebsiteDataStore expects (macOS 14+).
        let arr: *mut AnyObject = msg_send![objc2::class!(NSArray), arrayWithObject: proxy as *mut AnyObject];
        let _: () = msg_send![store, setProxyConfigurations: arr];
    });
}
```
